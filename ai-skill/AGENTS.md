# Agent instructions

For any system architecture, scalability, reliability, or production-readiness task, read `SKILL.md` and follow its workflow. Read `references/skill-router.md` to choose relevant specialist skills under `skills/`. For full designs, always include security/privacy, operations/reliability, and verification review. Use the templates when they fit the requested output. Do not claim zero errors; distinguish verified results from assumptions and unverified risks.

This package is agent-neutral. Do not assume a vendor-specific invocation syntax, tool integration, or filesystem location. If the host cannot read files, ask the user to provide the relevant skill text or include it in project instructions.
