# قائمة مراجعة التصميم المعماري

استخدمها كبوابة مبنية على المخاطر. صنّف كل بند: **اجتاز** أو **فشل** أو **لا ينطبق** أو **غير متحقق**. عدم وجود إجابة لا يعني الاجتياز. لكل فشل سجّل المالك والأثر وخطوة الإصلاح أو التحقق.

## النطاق والمتطلبات
- [ ] المستخدمون والتدفقات الأساسية والاستبعادات والواجهات وحدود النظام موضحة.
- [ ] الحقائق المؤكدة مفصولة عن الافتراضات والتقديرات.
- [ ] أهداف الجودة قابلة للقياس ولها طريقة قياس.
- [ ] قيود المستأجر والجغرافيا والامتثال والاحتفاظ والميزانية والقدرات التشغيلية مدروسة.
- [ ] لكل متطلب مكوّن أو عقد يحققه، أو قرار صريح بأنه خارج النطاق.

## الحمل والسعة
- [ ] متوسط QPS وذروته محددان لكل عملية وبالوحدات والمصدر.
- [ ] أحجام الحمولات ونسبة القراءة/الكتابة والتزامن والاندفاع والنمو والانحراف محسوبة.
- [ ] تقدير التخزين يشمل الاحتفاظ والفهارس والبيانات الوصفية والنسخ والنسخ الاحتياطية وهامش النمو.
- [ ] تقديرات الشبكة والنسخ بوحدات متسقة.
- [ ] حجم الذاكرة المخبئية يراعي عدد المفاتيح وحجم القيم وحمل البيانات الوصفية؛ لا تفترض نسبة الإصابة من دون دليل.
- [ ] الاختناقات وسعة الاسترداد وتصريف الطابور وإعادة التوازن محسوبة.
- [ ] أُعيد فحص الحسابات عالية الأثر؛ ودقتها مناسبة لقوة الدليل.

## البيانات والصحة
- [ ] مصدر الحقيقة وملكية كل كيان مهم مسميان.
- [ ] الاستعلامات والفهارس وأنماط الوصول والاتساق والترتيب وحدود المعاملات محددة.
- [ ] الثوابت وشذوذات التزامن المطلوب منعها صريحة.
- [ ] عولجت الطلبات المكررة والإعادات والمهلات الملتبسة والخمول تجاه التكرار.
- [ ] توافق مخطط API/الحدث يغطي الإصدارات المتتابعة وإعادة التشغيل والتاريخ المخزن.
- [ ] الحذف والاحتفاظ والنسخ والاستعادة وانتشار الحذف إلى البيانات المشتقة محددة.
- [ ] إبطال الذاكرة والقراءات القديمة وإعادة البناء والمصالحة مغطاة.

## الأنظمة الموزعة والفشل
- [ ] عطل الشبكة أو العقدة والاعتمادات البطيئة والفشل الجزئي والحمل الزائد محللة.
- [ ] لا تُعامل المهلة كدليل على أن العملية لم تحدث.
- [ ] يتضمن تحويل القائد سلوك fencing/epoch عند احتمال الكاتب القديم.
- [ ] ضمانات النسخ تغطي الكتابات المُقَرّ بها والتأخر والتعارض والإصلاح.
- [ ] قُيّمت مفاتيح التقسيم للانحراف والمفاتيح الساخنة وتركيز المستأجر وتفرّع الاستعلام.
- [ ] الضغط العكسي وامتلاء الطابور والرسائل السامة وعواصف الإعادة والرسائل الميتة/إعادة التشغيل محددة.
- [ ] لا تستخدم الساعات لإثبات السببية دون افتراضات؛ وتتحمل عقود الإيجار/الانتهاء الانحراف المطلوب.
- [ ] أُخذت الأعطال المشتركة ومزودو المناطق/الخدمات في الحسبان.

## الأمن والخصوصية
- [ ] الأصول وحدود الثقة وأنواع الجهات وسوء الاستخدام المحتمل محدد.
- [ ] المصادقة والتفويض منفصلان وأقل الامتياز مطبق وهويات الخدمات محدودة.
- [ ] عزل المستأجر وفحوص ملكية الكائن مطبقة في المسار المناسب.
- [ ] الأسرار خارج المستودع ويمكن تدوير المفاتيح وإلغاء الاعتمادات طارئًا.
- [ ] البيانات الحساسة محدودة ومشفرة ومخفاة عن السجلات وتحذف وفق السياسة.
- [ ] للواجهات العامة تحقق وحدود حجم/زمن/معدل وضوابط إساءة.
- [ ] سلسلة توريد البرمجيات والتبعيات وصلاحيات النشر والتدقيق مدروسة.
- [ ] التهديدات المتبقية والافتراضات موثقة؛ لا توصف المنظومة بأنها «آمنة» بلا تحفظ.

## الاعتمادية والعمليات
- [ ] مؤشرات/أهداف الخدمة ومئينات الزمن والحداثة والمتانة وRTO/RPO معرفة عند الحاجة.
- [ ] المقاييس والسجلات والآثار ولوحات المعلومات والتنبيهات مرتبطة بمالكين.
- [ ] التدهور الرشيق والتخلص من الحمل والعزل والمهلات وميزانيات الإعادة متناسقة.
- [ ] النشر والترحيل والتراجع والاسترداد آمنة عند الاكتمال الجزئي.
- [ ] سلامة النسخ وزمن الاستعادة اختُبرا أو وُسما صراحة بأنهما غير متحقق منهما.
- [ ] حدود السعة والملكية التشغيلية وأدلة التشغيل والتصعيد واضحة.
- [ ] للنشر والترحيل مسار تراجع أو استرداد.

## جودة المعمارية والأدلة
- [ ] كل اختيار رئيسي يحقق مطلبًا معلنًا وله بديل واحد على الأقل جرى النظر فيه.
- [ ] الخدمات والذاكرة والطوابير والمناطق والأجزاء الإضافية مبررة بدليل أو قيد واضح.
- [ ] الضمانات والحدود الخاصة بالمنتج الحالي مُثبتة بوثائق رسمية عند أهميتها.
- [ ] كلف التشغيل والتعقيد الجديد معلنة.
- [ ] المخططات تطابق العقود والتدفقات وحدود الثقة.
- [ ] الاختبارات المعلن نجاحها نُفذت فعلًا؛ وما لم يُتحقق منه موسوم.
- [ ] استُدعيت مهارات البيانات والأمن والاعتمادية والاتساق للقرارات عالية الأثر.
- [ ] عدم اليقين والمخاطر والخطوات التالية والمراجع المالكة واضحة.

## بوابة القرار

لا تصف التصميم بأنه جاهز للإنتاج إذا بقي خطر حرج للصحة أو الأمن أو فقد البيانات أو الاستعادة في حالة **فشل** أو **غير متحقق**. صعّد البنود الحرجة إلى مالك بشري مسؤول. تقلل هذه القائمة السهو لكنها ليست إثباتًا للسلامة أو الصحة.
