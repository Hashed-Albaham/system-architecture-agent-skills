# مهارات وكيل هندسة الأنظمة

[العربية](README.ar.md) · [English](README.md)

حزمة مهارات محايدة وقابلة للنقل لوكلاء الذكاء الاصطناعي التي تصمم الأنظمة الإنتاجية وتراجعها وتطورها. تضم نقطة دخول رئيسية وعشرة تخصصات، ورسومًا توضيحية باللغتين، وأدلة وقوالب وقوائم تدقيق وخريطة دراسة إنجليزية لفصول الكتابين.

## التحقق والحدود

تفحص GitHub Actions بنية الملفات وروابطها وبيانات المهارات وتغطية الفصول. هذه الفحوص لا تصادق على أي تصميم معماري بعينه. تساعد المواد على تقليل السهو لكنها لا تضمن انعدام العيوب أو الأمان المطلق. ملخصات الكتب أصلية وموجزة، وملفات PDF غير مضمّنة.
